# BKrFQG Rechnungen – Hilfe für die Berufskraftfahrer-Weiterbildung

Dieses Projekt ist eine Sammlung von Rechnern und Hilfsmitteln, die speziell für die Vorbereitung auf die IHK-Prüfungen für Berufskraftfahrer entwickelt wurden. Es bietet einen schnellen und übersichtlichen Zugriff auf Berechnungen, die für den Arbeitsalltag und die Weiterbildung essenziell sind.

## 🚀 Zugriff auf die Tools
Hier geht es zur Online-Version der Tools:
**[https://dervicblog.github.io/BKrFQG-Rechnungen/](https://dervicblog.github.io/BKrFQG-Rechnungen/)**

## 🧮 Enthaltene Rechner
Das Projekt umfasst folgende wichtige Berechnungen:

* **Achslastverteilung**
* **Anzahl der Zurrgurte**
* **Brutto-Netto-Gewicht**
* **Geschwindigkeit**
* **Kraftstoffverbrauch**
* **Ladevolumen**
* **Ladungssicherung**
* **Nutzlast**
* **Prozentrechnung**
* **Restlenkzeit**
* **Sicherheitsabstand**
* **Zurrwinkel**

## 🛠️ Technologien
Das Projekt ist als statische Webseite konzipiert, was einen schnellen und einfachen Zugriff direkt über den Browser ermöglicht – ideal zum Lernen oder für den Einsatz unterwegs.
